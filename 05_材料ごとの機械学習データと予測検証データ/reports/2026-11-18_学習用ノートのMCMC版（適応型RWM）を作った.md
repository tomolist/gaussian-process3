# 学習用のノートの MCMC 版（適応型 RWM）を作った

## やったこと

- **依頼（11-17）**：学習用のノートで、対数周辺尤度（LML）の決め方を、勾配法（L-BFGS-B）から適応型 RWM の MCMC に変え、専用の学習コードフォルダに保存する。
- **ユーザーの決定（相談のうえ）**
  - 係数 θ（E_h・E_v）も、カーネルのハイパーパラメータと一緒に MCMC でサンプリングする（②。格子は使わない）。
  - 予測は、事後サンプルの予測を混ぜた分布（混合分布）で出す。
  - 結果は、最新の学習結果フォルダの隣の `<N回目>_<材料フォルダ>_学習結果_MCMC/` に置く。
  - ノートは 5 つすべて（共通・解説付き・PP_・MIXPP_・GPPS_）。
  - コードの前に、今の格子の方法について、質問対策に E の 2 問を足す（済み。[[08_機械学習/01_ガウス過程回帰2_202610から/ガウス過程回帰2_機械学習/05_材料ごとの機械学習データと予測検証データ/reports/2026-11-17_質問対策に係数Eとその求め方の質問を足した|報告ノート]]）。
- **MCMC の部品** `04_補助スクリプト/mat_mcmc.py` を作った（中身をノートのセルにそのまま入れる。単独でも import できる）。
  - パラメータ：カーネルのハイパーパラメータ（対数）＋ 係数（B は横と縦、A は縦だけ、C はなし）。
  - 事前分布：カーネルは探索の範囲の中で対数一様、係数は設定 `SHIFT_PRIOR` の範囲で一様（既定は勾配法版の格子の範囲）。
  - 対数事後確率：sklearn の `log_marginal_likelihood` と同じ式（シフトの量は係数に比例するので、係数 1 の量を先に計算）。
  - 適応型 RWM：本体の手順5b と同じ方式（調整期間に Haario 型で共分散、採択率 0.234 を目標に歩幅を合わせ、本番は固定）。4 チェーンを並列に回す。
  - 収束：ArviZ の R-hat ≤ 1.01・ESS(bulk) ≥ 400。届かなければ、本番を続きから足す（上限 100000 回）。
  - 支持の判定：A は縦の係数の 95% 区間が 0 を含まない。B は (0, 0) が 95% の楕円の外（マハラノビス距離² > 5.99）。
  - 最終モデル：代表点（対数事後確率が最大のサンプル）の GPR に、予測用の事後サンプル 200 組を足したもの。`predict` は混合分布（平均 = mean(μ_i)、分散 = mean(σ_i² + μ_i²) − 平均²）を返す。
  - 結果のフォルダの名前に「MCMC」がなければ止める（勾配法版の結果の上書きを防ぐ）。
- **ノートの生成スクリプト** `04_補助スクリプト/build_mat_shift_mcmc_nb.py` を作った。
  - 勾配法版の生成スクリプト（`build_mat_shift_nb.py`）で作ったノートを `_tmp` に出し、セルを置き換えて作る（置き換えは、元の文がちょうど 1 回あることを確かめる）。

## AIが判断したこと

- **事前分布**：係数は、勾配法版の格子の範囲で一様にした（アレニウス型 E_h −20〜40・E_v −20〜60 kJ/mol、WLF 型 −20〜40）。カーネルは、探索の範囲の中で対数一様にした（本体の手順3c・5b と同じ）。
- **出発点**：既定 `MCMC_INIT = "mle"`（係数 0 で L-BFGS-B により最尤推定したカーネルに、チェーンごとのずれを足す。ノイズにはずれを足さない）。勾配法は出発点を決めるだけに使う。
- **B の支持の判定**：2 つの係数の事後分布を正規分布で近似し、(0, 0) のマハラノビス距離² が 5.99 を超えれば支持とした。勾配法版の ΔLML 3.0 にあたる。
- **代表点**：対数事後確率が最大のサンプル。ハイパーパラメータの表・特徴スケール・カーネル行列の図に使う。予測には使わない。
- **予測の 95% 区間**：混合分布の平均 ± 1.96 × 標準偏差（正規分布で近似）。
- **事後サンプルの CSV**：1 万行までに等間隔に間引く。
- **予測用の GPR の覚え方**：中身の指紋で覚え、6 モデルまでにした。セルを実行し直したときに、古いものを取り違えないため。
- **変えなかった部分**：外れ値の検知（規則 f）の GPR と Cross-WLF の当てはめは、勾配法版のまま（データの確認と参考のため）。WLF 型の A2 を読むので、`FORM_CFG` は設定に残した。
- **表示の桁**：事後分布の値は桁が長いので、係数の表示を有効数字 3 桁にした。まとめの表の θ の列は、A では縦の係数だけを書く（勾配法版は「E_h 0［0〜0］」も書く）。
- **ユーザーの手の直しは入れていない**：勾配法版の共通のノートと PP_ には、図の設定の手の直しがある（セル14 の `VALID_FIGSIZE` (5, 5)・`VALID_MARKER` 10・`VALID_POINT_EDGE` 0.3 など、セル16 の `FLOW_FIGSIZE` (6, 5)・`FLOW_FONT`・`FLOW_MARKER` 100 など）。MCMC 版は生成スクリプトの既定の値のまま。
- 報告ノートの日付は、作業を終えた 11-18 にした（始めたのは 11-17）。
