## 結果（数値・図）

- **図**：すべて、表示の前に 600 dpi の PNG で保存している（`save_fig` などは、保存してから表示する）。ノートに表示されない図もある（主のモデル以外の図など）。
- **表**：表示する表は、すべて CSV に保存している（`データの概要.csv`〔選んだデータのファイルの場所を含む〕・`シフトファクターの推定.csv`・`ハイパーパラメータ.csv`・`予測検証_3data_指標.csv`・`まとめ.csv` など）。
- **判定**（`>> 判定：…`）：OK も ★要確認 も、すべて `判定の一覧.csv` に保存している。
- **出力にしか残らないもの**（クリアすると消える）：
  - 2 つのノートとも：Python の場所と版、計算にかかった時間、0 以下の値で自動で除いた行のファイル名（件数は CSV に残る）、カーネルの式の文字列（値は `ハイパーパラメータ.csv`）、保存先の案内、警告やエラー。
  - 検討用だけ：まとめの「学習用のノートの `SHIFT_COL`・`SHIFT_FORM` の候補」の文（`まとめ.csv` の列から、同じ候補が分かる）。
  - 学習用だけ：特徴スケールの文（値は `ハイパーパラメータ.csv`）、Cross-WLF の「学習の残差」（`予測検証_3data_指標.csv` の Cross-WLF の行の `mean_sd` と同じ値）、外れ値の節の候補の件数（`問題の候補.csv` から数えられる）、**依存性グラフのセルの「（参考）Tset だけを動かしたときの η 比」**。この比の数値だけは、どのファイルにも残らない（曲線は `依存性グラフ.png` で見られる）。
- **どのデータを選んだか**は、出力のほかに 2 か所に残る。
  - `<学習結果フォルダ>/データ確認/データの概要.csv` の「ファイル」の列（学習 5data・検証 3data の 2 行。リポジトリの中のファイルは、リポジトリ直下からの相対パス、外のファイルは絶対パス）。行数・条件数・設定温度・厚み・射出速度も入る。CSV なので Git で管理される（学習結果フォルダがリポジトリの中のとき）。
  - モデルごとの `学習済みモデル_<記号>.joblib` の「学習データのファイル」・「検証データのファイル」（Git の管理外）。厚みごとの比較のノートと `mat_seed_check.py` は、ここからデータの場所を読む。
  - 注意：`データの概要.csv` は、学習結果フォルダごとに 1 つで、検討用・学習用、全ショット版・条件ごとの平均版で共通なので、最後に実行したノートの分で上書きされる。同じ学習結果フォルダで違うデータを使うと、ほかのノートの結果がどのデータのものかは、`.joblib` の記録でしか分からない。
- 結論：出力をクリアしてコミットしてよい。ノートを未実行の形で Git に置き、結果はフォルダに置くという、このリポジトリの決まり（CLAUDE.md §8）にも合う。

## AIが判断したこと

- 「出力をクリアしてコミットする」のをおすすめとして答えた。理由：結果はフォルダに保存されている。図を入れたままだとノートのファイルが大きくなり、差分も読みにくい。ノートは生成スクリプトで作り直すと未実行の版に置き換わる。
- コミットの前の注意として、次の 2 つを書き足した。設定エリアの書き換えは出力のクリアでは消えないこと（特に `FILES` にプロジェクトの外のパスを書いたら、コミットしない）。結果のフォルダの図（PNG）と学習済みモデルは Git の管理外で、CSV だけが管理されること。

- 続けての問い（選んだデータの記録）は、同じ話題で、この報告ノートもまだ未確認・未コミットなので、新しい報告ノートを作らず、この報告ノートに書き足した。
