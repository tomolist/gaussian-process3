## やったこと

- ユーザーの問い（11-15）：「温度シフトファクターが本当に必要なのかをさらに確実にするために、3 材料のデータにおいて、それぞれ 3 条件ずつある加熱シリンダ温度条件のうちの一条件を予測精度検証用データに使って、他の条件データで学習を行うことを全パターン（3 通り）を行う新たな本番学習用ノートを作成することは可能ですか？」
  - 答え：作れる。計画を出し、ユーザーの「続けて」（11-16）で作った。
  - ユーザーの決定（11-15）：
    - 学習は、残りの 2 温度の 5data だけ。検証の主は、除いた温度の 5data。除いた温度の 3data は、別に集計する。
    - Claude は試しの実行まで。本番の実行は、ユーザーがダイアログで行う。
- 生成スクリプト `04_補助スクリプト/build_mat_loto_nb.py` を作り、未実行のノートを置いた：`01_機械学習コードフォルダ/材料別_温度シフトファクター検討/材料別_温度シフト機械学習コード/材料別_温度ホールドアウト検証_ARD対応Matern52＋線形＋ホワイトノイズ.ipynb`（29 セル）。
- ノートの中身：
  - 回：材料ごとに、5data の設定温度を 1 つずつ除く 3 回と、参考の「全温度」の回（`REF_ALL`。シフトファクター検討用のノートと同じ学習）。
  - 比べるモデル（回ごとに、その回の学習データだけで学習）：
    - シフトのあるモデル（既定 `A_Tset_Arr`・`B_Tset_Arr`。設定 `SHIFT_COLS`・`STRUCTS`・`SHIFT_FORMS`）
    - `C`（Tset を GP の普通の入力にする）
    - `C_noTset`（Tset を使わない。入力 ln γ̇・ln P3_3・ln Tff。A_Tset・B_Tset の θ = 0 と同じモデル。ノートの中だけで `layout` を包んで足した。Tff の入力の有無の比較のノートの `C_noTff` と同じやり方）
  - 手順：
    1. 分け方（判定：学習は 2 温度、検証は除いた温度だけ、条件の重なりなし、温度だけの外挿か、行数の合計）
    2. 回ごとのプロファイル尤度（`run_profile`）
    3. 念入りな最適化と C・C_noTset の学習
    4. 局所解の見直し（下の「AIが判断したこと」）
    5. ハイパーパラメータと学習済みモデルの保存
    6. 除いた温度の予測と指標（5data・3data 全体・低速側・高速側・合計）
    7. 図
    8. まとめ
    9. 判定の一覧
  - まとめ：除いた温度の 5data の RMSE を、回ごとに C_noTset と比べ（比が 1/1.1 未満を「良い」、1.1 超を「悪い」）、「要る／どちらかといえば要る／どちらでもよい／どちらかといえば要らない／要らない／決まらない」の目安を出す。
- 試しの実行（5 回。`_tmp/loto_1115/`。通常版のデータ、時間を短くする設定：`PROFILE_RESTARTS = 0`・`N_RESTARTS = 2`・`SHOW_FIGS = False`）：
  1. GPPS だけ、A と B（格子を 10 刻みに粗くし、区間の延長は 3 回まで）
  2. 3 材料、A だけ（格子は本番と同じ）→ まとめの表の列名と、局所解の問題が見つかった
  3. 3 材料、A だけ（まとめの表の列名を直した後）
  4. 3 材料、A だけ（局所解の見直しを足した後）
  5. 3 材料、A だけ（見直しの後の区間の延長を足した後）。あわせて、GPPS の A と B で、見直しを必ず行う設定（`LML_CHECK = -1e9`）でも流し、B でも見直しのコードが最後まで動くことを確かめた
- 最後の版で、すべてのセルがエラーなく終わった。置いたノートは、5 回目の写し（`_tmp/loto_1115/loto_v5.ipynb`）と同じ中身（`cmp` で確かめた）。

## AIが判断したこと

- **局所解の見直しを足した**（計画になかった）：
  - 2 回目の試しの実行で、粉砕材混合 PP の 210 ℃ を除く回の A_Tset_Arr が、LML の低い解に止まっていた。最良 782.37 で、同じモデルにあたる C_noTset（796.07）より低かった。
  - また、C の LML が C_noTset より 10〜30 低い回が 5 つあった。
  - 2 温度だけの学習では局所解に止まりやすいので、ノートに次の 2 つを足した。
    - (a) C_noTset の学習の LML が、シフトのモデルの θ = 0 より `LML_CHECK`（1.0）以上高いとき：格子の全点を C_noTset の解から最適化し直し、区間の延長もやり直してから、最良の θ と θ = 0 を学習し直す。
    - (b) C が C_noTset より `LML_CHECK` 以上低いとき：C_noTset の解（Tset の長さスケールを 50 にしたもの）からも C を学習し、LML の高いほうを使う。
  - 見直しで、粉砕材混合 PP の結論が「決まらない」から「どちらかといえば要る」に変わった。PP の C の比も 2.9 → 1.3 になった（230 ℃ を除いた回）。
- **C_noTset は、このノートの学習と、シフトのモデルの θ = 0 の念入りな最適化のうち、LML の高いほうを使う**：同じモデルなので、最適化がよく進んだほうを使うだけ。
- **判定と目安の基準**：
  - RMSE の比の基準 1.1（今のノートの「C の 1.1 倍以内」と同じ考え方）、被覆率 0.8、`LML_CHECK` 1.0 は、Claude が決めた。
  - まとめの 6 つの目安（要る〜決まらない）の分け方も、Claude が決めた。
  - 結論の主は、ユーザーの決定どおり、除いた温度の 5data。
- **既定の設定**：
  - `SHIFT_FORMS = ["arrhenius"]` と `STRUCTS = ["A", "B"]`：本番の設定の報告書の候補（A_Tset_Arr・B_Tset_Arr）に合わせた。
  - `REF_ALL = True`：係数の安定を見るため。
  - ほかは、今のノートと同じ値。
- **まとめの表の列名**：材料によらない「低い温度・中の温度・高い温度」にした（材料で設定温度が違う〔GPPS は 200・220・240 ℃〕ため）。除いた温度の値は、列「除いた温度」に書く。
