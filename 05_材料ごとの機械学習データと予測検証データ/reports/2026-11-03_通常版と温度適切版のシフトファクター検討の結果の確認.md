### 温度のシフトが尤度で支持されるか（ΔLML。基準 3.0 以上）

| モデル | PP 通常 / 適切 | 粉砕材混合PP 通常 / 適切 | GPPS 通常 / 適切 |
|---|---|---|---|
| B_Tset_Arr | **3.2** / 0.8 | **9.6** / **5.3** | **22.6** / **11.3** |
| B_Tset_WLF | 1.9 / 0.3 | **7.3** / **3.6** | **19.5** / **10.4** |
| A_Tset_Arr | **3.3** / 0.8 | **9.6** / **5.3** | **20.3** / **9.9** |
| A_Tset_WLF | 1.9 / 0.3 | **7.0** / 3.0（計算し直すと **3.1**） | **17.2** / **8.9** |
| B_Tff_Arr・WLF | 1.1・0.9 / 0.1・0.1 | 0.3・0.6 / 0.7・0.7 | 2.5・2.2 / 2.0・1.3 |
| A_Tff_Arr・WLF | 1.1・0.9 / 0.1・0.1 | 0.3・0.2 / 0.7・0.3 | 0.5・0.0 / 0.9・0.2 |

- **Tset のシフト**：通常版は 3 材料とも支持（PP はアレニウス型だけ、ぎりぎり）。温度適切版は、粉砕材混合PP と GPPS で支持、PP は支持されない。
- **Tff のシフト**：どの材料・版でも支持されない。粉砕材混合PP・GPPS では縦の係数が負（「高温ほど粘い」の向き）で、シフトすると曲線がかえって離れる（判定の ★ の多くはこれ）。
- 横の係数はほぼ 0（PP・粉砕材混合PP は E_h 0、GPPS は E_h 1・A1_h 0.25）。そのため、A（縦だけ）と B の差は小さい（PP・粉砕材混合PP は ΔLML の差 0.1 以下。GPPS は B が A より LML で 2.2〔通常版〕・1.4〔温度適切版〕高い）。
- 型：Tset のシフトでは、6 組すべてでアレニウス型の LML が WLF 型より高い（差 0.5〜3.0）。
- 通常版の PP・粉砕材混合PP は、10-23 の結果（アレニウス型の B_Tset）と数値まで一致した。GPPS の WLF 型は、細かい格子を 0.25 刻みにしたので、10-23 の ΔLML 16.0（A1_h 0）より大きい 19.5（A1_h 0.25）。

### 見つけた問題：プロファイル尤度の格子の計算が、局所解に止まった所がある

- 格子の計算は、同じ横の係数の列を縦の係数の小さい順に進め、前の点の解を初期値にする。各点の最適化は「前の点の解から 1 回＋乱数の初期値から 1 回」（`PROFILE_RESTARTS = 1`）。ノイズの大きい悪い解に入ると、次の点に引き継がれて抜けにくい。
- **温度適切版の粉砕材混合PP の Tset のシフト 4 モデル**が、はっきり止まっていた。縦の係数の小さい側（例：A_Tset_WLF の A1_v 0〜2.75）で、LML が約 30 低く、ノイズも大きい（0.0088 対 0.0074）。θ = 0 の点も、格子 658.0 に対して念入りな最適化 687.8。

## AIが判断したこと

- 局所解の疑いは、「隣の点と LML が 10 以上違い、かつノイズの標準偏差が 12% 以上違う」で見分けた（係数の向きで本当に急に変わる所は、ノイズはなだらかに変わる。通常版の E_h の向きで確かめた）。
- 計算し直しは、ノートと同じやり直し回数（1 回）で、初期値だけを最良の点の解にした。新しい LML と元の LML の大きいほうを採った。95% 区間の計算し直しは、計算した格子の点の中だけで決めた（細かい格子の外には広げていない）。
- A と B、アレニウス型と WLF 型の比べ方（同じパラメータの数なら LML の差、1 つ多い B は 1.92 を目安）は、Claude の読み方（要確認）。
