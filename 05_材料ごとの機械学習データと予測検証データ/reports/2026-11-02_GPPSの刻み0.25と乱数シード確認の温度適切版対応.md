# GPPS の細かい格子を 0.25 刻みに、乱数シードの確認を温度適切版のデータでも動くように

## やったこと

- ユーザーの決定（[[08_機械学習/01_ガウス過程回帰2_202610から/ガウス過程回帰2_機械学習/05_材料ごとの機械学習データと予測検証データ/reports/2026-11-02_細かい格子FINE_AとGPPSの刻みの修正|2026-11-02_細かい格子FINE_AとGPPSの刻みの修正]] の「未解決・次にやること」への回答）に従って、次の 3 つを行った。
  1. **GPPS の細かい格子を 0.25 刻みに**：`SHIFT_CFG` の GPPS の `"fine"` を `(2.0, 0.5)` → `(2.0, 0.25)` にした（共通部品 `mat_common.py` の既定と、学習用・検討用の生成スクリプトの設定エリア、解説ファイル）。5 つのノート（学習用・検討用・厚みごとの比較・解説付き 2 つ）を、今の版を `_to_delete/` へ移してから、生成スクリプトで作り直した。前のコミット（`cc1cf85`）との違いは、GPPS の行（と、その解説の行）だけ。
  2. **乱数シードの確認（`mat_seed_check.py`）を、通常版と温度適切版の両方で動くように**：検証データにある範囲（低速側・高速側・範囲内）だけを記録する形にした。まとめの表と図の 2 枚目は、外挿の範囲のうち、低速側があれば低速側（通常版。前と同じ出力）、なければ高速側（温度適切版）を使う。新しいノートは作っていない（1 つのスクリプトで両方に対応できたため）。
  3. **検討用のノートの設定エリアの空行**：ユーザーが入れたものと分かったので、そのまま残した（生成スクリプトにも入れてある）。
- 確かめ：
  - 通常版：10-27 の試運転の結果（`_tmp/新構成の確認/本番PP/`）から、`mat_seed_check.py` が読むファイルだけを `_tmp/seed_check_normal/PP/` にコピーし（元の場所で実行すると、前の結果を上書きするため）、前と同じ引数（`shot 1 2`）で実行した。
  - 温度適切版：作り直した検討用のノートのコピーを、GPPS の温度適切版のデータで実行し（`_tmp/検討用_温度適切GPPS_実行用.ipynb`。結果は `_tmp/温度適切の確認/GPPS/`）、その結果で `mat_seed_check.py` を実行した。0.25 刻みの格子と、温度適切版のデータでのノートの動きも、これで確かめた。

## AIが判断したこと

- 乱数シードの確認は、新しいノートを作らず、今のスクリプトを直して両方に対応させた（ユーザーの指示の第 1 案）。通常版の出力（CSV の列・図）が前と変わらないように、まとめと図の 2 枚目は「低速側があれば低速側」とした。温度適切版では、そこが高速側になる。
- 通常版の確かめは、前の結果を上書きしないように、必要なファイルだけを別のフォルダにコピーして行った。
- ノートの実行用のコピーは、このプロジェクトの決まり（CLAUDE.md §8：`_tmp/` のコピーを `run_nb.py` で実行する）どおりに実行した（`run_nb.py` は、実行の結果をそのコピーに書き込む）。
- 説明書（`説明書_材料別温度シフトGPRのノート`）の乱数シードの確認の節には、低速側を前提にした記述がないので、直していない。
