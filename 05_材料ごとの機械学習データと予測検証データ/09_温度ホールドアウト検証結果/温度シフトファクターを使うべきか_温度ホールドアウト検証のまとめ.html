2026-11-16 に、温度ホールドアウト検証のノート（材料ごとの複製 PP_・MIXPP_・GPPS_温度ホールドアウト検証_…ipynb）を、3 材料の最新の学習結果フォルダ（PP 3 回目・粉砕材混合 PP 5 回目・GPPS 3 回目。線形項あり・通常版・全ショット版）で本番の設定で実行した結果（コミット be31c30）から作りました。

1. 結論

温度シフトファクター（加熱シリンダ温度 Tset のシフト）は、GPPS と粉砕材混合 PP では使ったほうがよく、PP では使わなくてよい。ただし、粉砕材混合 PP は差が小さく、GPPS は射出速度の外挿（3data）では逆の結果だった。
GPPSB_Tset_Arr

✓使ったほうがよい

ノートの目安：要る（良い 3・同等 0・悪い 0 回）

  • 除いた温度（200・220・240 ℃）の誤差が、3 回とも C_noTset（設定温度を使わない）より 12〜28% 小さい（比 0.715・0.747・0.881）。設定温度を GP の普通の入力にした C よりも小さい。
  • 3 回とも尤度で支持された（ΔLML 3.41・11.95・17.46、基準 3）。係数 E_v は 10・10・13 kJ/mol で、全温度の 9［7〜11］ に近い。
  • ただし、射出速度の外挿（3data）では、C_noTset のほうが誤差が小さかった（3.3 節）。
粉砕材混合 PPA_Tset_Arr

✓使ったほうがよい（差は小さい）

ノートの目安：要る（良い 3・同等 0・悪い 0 回）

  • 除いた温度の誤差が、3 回とも C_noTset より 9〜22% 小さい（比 0.908・0.784・0.899）。ただし 2 回は、「良い」の境目（0.909）のすぐ下。
  • C とはほぼ同じ（C との比 0.996・1.036・1.073）。シフトの形でも GP の入力でも、設定温度を使うと良くなる。
  • 係数 E_v は 5・4・7 kJ/mol で、3 回とも全温度の区間（5.5［3.5〜8］）に入る。尤度の支持は 3 回中 2 回。
PPA_Tset_Arr

—使わなくてよい

ノートの目安：どちらかといえば要らない（良い 0・同等 1・悪い 2 回）

  • 除いた温度の誤差が、C_noTset より 大きい回が 2 回、同等が 1 回（比 1.081・1.866・1.293）。C も 3 回とも C_noTset より大きい（比 1.229・1.981・1.333）。
  • 210・230 ℃ を除くと、係数 E_v が負になる（−9.5・−6 kJ/mol。高温ほど粘度が高い向き）。全温度の 3.5［1〜5.5］ から外れ、係数が安定しない。
  • PP では、設定温度の効果は、Tff（流動中樹脂温度）と P3_3 でほぼ説明できると読める。

2. 調べ方

温度シフトファクターの本来の役目は、学習にない温度の粘度を当てることです。そこで、材料ごとに 3 つの加熱シリンダ温度のうち 1 つを学習から除き、残りの 2 温度の 5data で学習して、除いた温度の 5data を予測しました。これを 3 つの温度すべてで行いました（3 回）。下の図は、その 3 回を順に見せています。

材料 回
温度シフトのモデルC（設定温度を GP の普通の入力にする）C_noTset（設定温度を使わない）

比べたモデルは 3 つです。比べの基準は C_noTset で、比（モデルの誤差 ÷ C_noTset の誤差）が 1/1.1 ≒ 0.909 より小さければ「良い」、1.1 より大きければ「悪い」、その間を「同等」としました。

温度シフトのモデル
設定温度 Tset による粘度のずれを、アレニウス型のシフトファクターで表すモデル。A_Tset_Arr は縦（粘度の向き）だけ、B_Tset_Arr は横（せん断速度の向き）と縦にずらす。係数 E_v・E_h［kJ/mol］はデータから決める。
C・C_noTset
シフトのない通常の GPR。C は Tset を GP の普通の入力にする。C_noTset は Tset を使わない（入力は ln γ̇・ln P3_3・ln Tff。シフトの係数を 0 にしたモデルと同じ）。
RMSE
予測の誤差（ln η の二乗平均平方根）。小さいほど良い。0.01 は粘度で約 1%。
ΔLML・尤度で支持
シフトの係数を 0 にしたときより、学習データの説明（対数周辺尤度）がどれだけ良くなるか。基準（A は 1.92、B は 3.0）以上で「支持」。
95% 区間
係数の、おおよその 95% の範囲（プロファイル尤度から）。

4. 読むときの注意

  • 学習は 2 温度だけです。温度の効果は 2 点の差でしか決まらないので、全温度で学習するときより係数がぶれやすくなります。両端の温度を除く回は温度の外挿、中の温度を除く回は内挿です。
  • C_noTset は設定温度を使いませんが、流動中樹脂温度 Tff と P3_3 を入力に使うので、温度の情報の一部はそれらが運びます。「温度をまったく使わない」モデルではありません。
  • 粉砕材混合 PP の「良い」は、3 回中 2 回が境目（0.909）のすぐ下です。乱数や最適化の局所解で、判定が 1 段変わりうる大きさです（短い設定の試しの実行では、230 ℃ の回が 0.915 で「同等」でした）。
  • どれも 1 回の実行（乱数シード 42）で、線形項あり・通常版・全ショット版の結果です。線形項なし・温度適切版では確かめていません。
  • 決めるのはユーザーです。この資料は、温度ホールドアウト検証のノートの「まとめ」の目安と、その根拠の数値をまとめたものです。
