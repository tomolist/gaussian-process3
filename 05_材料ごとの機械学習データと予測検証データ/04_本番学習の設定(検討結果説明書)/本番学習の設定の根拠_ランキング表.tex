\section*{この資料について}
\begin{itemize}[itemsep=0.2ex,topsep=0.3ex]
\item 「本番学習の設定の決定.pdf」の根拠を、\textbf{材料 × 学習データ（通常版・温度適切版）ごとに、すべてのモデルのランキング表}にしたものです（2026 年 11 月 6 日のユーザー依頼）。1 章に、流動中樹脂温度 Tff を GP の入力に使ったほうがよいかの表も載せました。
\item 数値は、検討結果フォルダの CSV から、生成スクリプト \texttt{04\_\allowbreak{}補助スクリプト/\allowbreak{}build\_\allowbreak{}report\_\allowbreak{}mat\_\allowbreak{}ranking.py} が読んだものです（学習はしていません）。読んだフォルダは付録の表~\ref{tab:files}。
\item \textbf{LML（対数周辺尤度）は、同じ材料・同じ学習データ（・同じ厚み）の中でだけ比べます}。材料や学習データが違うと、LML の大きさは、データの行数とばらつきで決まるためです。順位も、その中だけのものです。
\item パラメータの数（表の「数」）が多いモデルほど、LML は大きく出やすくなります。そのため、差には基準を当てます。係数 1 つで 1.92、2 つで 3.0 です（\textbf{$\Delta$LML} は、シフトの係数を 0 にしたモデルとの LML の差）。本番のモデルは、LML の順位だけでなく、この基準と「候補の選び方」（2026 年 11 月 3 日のユーザー決定）で決めています。そのため、LML が 1 位でないモデルが本番になることがあります。
\item モデルの記号は「構造\_シフトに使う温度\_型」です。構造 A は縦だけ、B は横・縦のシフト、温度は Tset（加熱シリンダ温度）・Tff（流動中樹脂温度）、型は Arr（アレニウス型）・WLF（WLF 型）。C はシフトなしで、4 変数（$\ln\dot\gamma$・$\ln$ P3\_3・$\ln$ Tff・Tset）を並べた通常の GPR。\texttt{C\_\allowbreak{}noTff} は C から Tff を外したもの（入力 $\ln\dot\gamma$・$\ln$ P3\_3・Tset）で、A\_Tff・B\_Tff の係数を 0 にしたものと同じモデルです。
\item {}†：\texttt{C\_\allowbreak{}noTff} の 3data の誤差は、2026 年 11 月 6 日の確かめの実行（\texttt{\_\allowbreak{}tmp/\allowbreak{}tff\_\allowbreak{}input/\allowbreak{}run3/\allowbreak{}}。Tff の入力の有無の比較のノート）の値です。同じノートを本物の学習結果フォルダで実行すれば、同じ値になります。LML は、検討の結果の \texttt{LML\_\allowbreak{}at\_\allowbreak{}0} から取りました（確かめの実行の値と一致）。
\end{itemize}

\begin{itemize}[itemsep=0.2ex,topsep=0.3ex]
\item \textbf{C（シフトなし）}：Tff を入力に足しても、6 つとも LML は基準（$+1.92$）まで上がりません（差 $= $ LML(C) $-$ LML(\texttt{C\_\allowbreak{}noTff})）。3data の誤差は 5 つで同等（比が 1/1.1〜1.1）です。温度適切版の粉砕材混合 PP だけ、Tff を外したほうが誤差が小さくなります（比 0.68。検証は高速側だけ）。
\item \textbf{Tff でシフトするモデル（A\_Tff・B\_Tff）}：Tff は入力ではなく、シフトに使います（GP の入力は $\ln\dot\gamma$・$\ln$ P3\_3・Tset）。そのシフトは、6 つとも支持されません（2 章の表）。係数 0 では \texttt{C\_\allowbreak{}noTff} と同じモデルです。
\item \textbf{Tset でシフトするモデル（A\_Tset・B\_Tset。本番の 5 つ）}：Tff を GP の入力に使います。\textbf{Tff だけを外した同じ構造のモデル（Tset のシフト ＋ $f(\ln\dot\gamma, \ln$ P3\_3$)$）は計算していないので、直接の答えはありません}。手がかりは 3 つです。① Tff の長さスケールは 8〜32 と長く（入力は標準化していて、データの幅は約 $\pm2$）、GP の Matern の部分は Tff の向きにほとんど変わりません。② Tff だけを入力にしたモデル（A\_Tset の係数 0）は、Tset だけを入力にしたモデル（\texttt{C\_\allowbreak{}noTff}）より LML が 2〜16 低く、温度の情報は Tset が持っています（表の右端）。③ 本番のモデルが \texttt{C\_\allowbreak{}noTff} より基準以上大きいのは、GPPS の 2 つだけで、これは Tset のシフトの効果です。
\item \textbf{まとめ}：今の結果には、Tff を入力に入れて良くなったという結果は、どの材料・学習データ・モデルにもありません。C では、入れなくてよい（温度適切版の粉砕材混合 PP は、外したほうがよい）と言えます。Tset でシフトするモデルは、上の①〜③から入れなくてよい見込みですが、確かめるには、Tff の入力の有無の比較のノートに「Tset のシフトのモデルから Tff を外したもの」を足して計算する必要があります。Tff はユーザー指定の説明変数なので、外すかはユーザーが決めます。
\end{itemize}

\section{厚みごとの根拠（ランキング表）}\label{sec:thick}
\begin{itemize}[itemsep=0.2ex,topsep=0.3ex]
\item 読んだ CSV（厚みごとの比較のノート）：\texttt{プロファイル尤度\_\allowbreak{}厚みごと.csv}（その厚みの 5data だけで係数を決め直したときの LML・係数・$\Delta$LML・取り直しが収束したか）、\texttt{温度シフトの確認\_\allowbreak{}厚みごと.csv}（全厚みのモデルで見た、その厚みの温度シフトの判定 ○・△・×）、\texttt{厚みごとと総合の比較.csv}（3data のその厚みの誤差〔粘度の \%〕。「厚みごと」はその厚みだけで学習したモデル、「総合」は全厚みのモデル）、\texttt{厚みごとの比較\_\allowbreak{}まとめ.csv}（組ごとの Tff か Tset か）。
\item LML は、その厚みの中だけで比べます。C の厚みごとの LML は残っていないので「---」です。\texttt{C\_\allowbreak{}noTff} の LML は、A\_Tff・B\_Tff の係数 0 の値です（LML $-$ $\Delta$LML の最大）。厚みごとの LML は、局所解のため最大 5.9 ほどの不確かさを含みます（1 章の表~\ref{tab:tffthick} の下）。差が 1〜3 程度の順位の入れ替わりは、意味のある差とは言えません。
\item 「印」：本番＝全厚みで選んだモデル（厚みごとの学習にも、このモデルを使う）。厚みの規則＝その厚みのプロファイル尤度に「候補の選び方」を当てたときの候補（参考）。§：縦の係数が負（低温ほど粘度が低いという、逆の向き）。
\item 「確認」：○＝温度の順序と温度による粘度の比が実測と合い、換算でずれが減る。×＝予測の温度の順序が実測と逆。△＝それ以外。
\end{itemize}
