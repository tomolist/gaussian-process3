## 1. 背景（30 秒で）

- 材料別の温度シフト GPR（CLAUDE.md §9 の別プロジェクト）の学習用のノートには、2 つの版がある。
  - 勾配法版：`01_勾配法（L-BFGS-B）/`
  - MCMC 版：`02_MCMC(適応型RWM)/`。2026-11-17〜18 に作った。
- MCMC 版は、係数 E（温度シフトファクターの係数）とカーネルのハイパーパラメータを、適応型 RWM の MCMC でまとめてサンプリングする。予測は、事後サンプル 200 組の混合分布。
- MCMC 版は試しの実行（短い設定）しかしていない。この計画で、勾配法版の最新の結果と同じデータ・同じモデルで本番の実行をし、2 つの版を比べる。
- 詳しくは次を読む。
  - 報告ノート `05_材料ごとの機械学習データと予測検証データ/reports/2026-11-18_学習用ノートのMCMC版（適応型RWM）を作った.md`
  - `CLAUDE.md` §9 の「学習用のノートの MCMC 版」の項目

## 4. 実行の手順

コマンドはリポジトリ直下から、1 つずつ打つ。長い実行は、Bash の `run_in_background` で回し、終わりの知らせを待つ（途中で何度も見に行かない）。

1. **全厚みの 3 回**（目安 1〜1.5 時間。収束せず本番を足すと、最大で約 4 時間）
   ```
   uv run python 00_実行待ち_MCMC版の本番実行/run_all.py --only PP_all MIX_all GPPS_all
   ```
2. **途中の確かめ**
   ```
   uv run python 00_実行待ち_MCMC版の本番実行/summarize.py
   ```
   収束（5 節）を見る。問題がなければ次へ。
3. **厚みごとの 11 回**（目安 約 30 分。1 回 2〜3 分。長くても 1 時間ほど）
   ```
   uv run python 00_実行待ち_MCMC版の本番実行/run_all.py
   ```
   結果がある実行（全厚みの 3 回）は、自動で飛ばす。
4. **まとめ**：もう一度 `summarize.py` を実行する。
   - 出力は `_tmp/mcmc_prod_run/比較_<日時>.csv`（材料 × 厚み × 版）と `…_要確認の判定.csv`。
   - 実行の状況は `_tmp/mcmc_prod_run/進行状況.csv`。ログは `_tmp/mcmc_prod_run/logs/`、実行したノートのコピーは `_tmp/mcmc_prod_run/nb/`。

時間の根拠（11-18 の試しの実行）
- 1 回の尤度の計算：PP 19 ms、GPPS 5 ms。並列の 4 チェーンでは、短い設定で PP 1 反復 約 36 ms。
- 図を描くセルは、予測 200 組で数分かかる。
- 粉砕材混合 PP・C・厚み 1.0 mm（120 行）を既定の反復数で実行すると、全体で約 2 分だった。

## 5. 結果の確かめ方（モデルのフォルダごと）

- **できるファイル**（モデルのフォルダ）
  - 勾配法版と同じ図と表に加えて、`MCMC_事後サンプル.csv`・`MCMC_収束の診断.csv`・`事後分布の要約.csv`・`事後分布_係数.png`・`事後分布_ハイパーパラメータ.png`・`MCMC_トレース.png`。
  - プロファイル尤度の図と表、損失関数の推移の図は、MCMC 版にはない。
- **収束**：`MCMC_収束の診断.csv`、または `summarize.py` の「MCMC の収束」の表で見る。
  - R-hat の最大が 1.01 以下、ESS(bulk) の最小が 400 以上、本番の採択率が 0.15〜0.40。
  - 届かないときは、6 節のとおりにする。
- **事前分布の端**：判定の一覧に「係数の 95% 区間が、事前分布の範囲の端に届いていない」の ★ が出たら、`SHIFT_PRIOR` を広げてやり直すか、ユーザーに相談する。
  - カーネルのハイパーパラメータ（特に線形項の σ0、C の長さスケール）が範囲の端に届くのは、よくあること（参考表示だけ）。
- **勾配法版との比べ**（`summarize.py` の表）
  - 係数（勾配法版：格子の最良と 95% 区間 ↔ MCMC 版：事後分布の中央値と 95% 区間）
  - 支持（ΔLML ↔ 事後分布）
  - 3data の RMSE（全体・低速側・高速側）、被覆率
  - 短い試し（11-18）では、GPPS の全厚みで両者がよく合った：E_h 1［1〜1］↔ 0.994［−0.008〜1.80］、E_v 9［7〜11］↔ 9.30［6.18〜12.2］、RMSE 全体 0.1213 ↔ 0.1212。
  - PP の全厚みは、どちらでも支持されない見込み（勾配法版は ΔLML 0.05）。
- **★ の想定内のもの**：厚みごとの回では、3data に低速側がない厚みがある（RMSE 低速側が空）。被覆率が 0.8 未満で ★ になる厚みは、勾配法版にもある（例：粉砕材混合 PP 1.0 mm で 0.53）。勾配法版と同じ傾向かを見る。

## 6. 困ったとき

- **収束しない**（上限 100000 回でも ★）
  - まず、その回の `MCMC_トレース.png` を見る（チェーンが別々の所にとどまっていないか）。
  - やり直すときは、その回のモデルのフォルダを `_to_delete/` へ移し（元のフォルダ構成を保つ。`mv -n`。移せたかを確かめ、`_to_delete/記録.md` に 1 行）、上限を上げて実行する。
    ```
    uv run python 00_実行待ち_MCMC版の本番実行/run_all.py --only <ID> --set "MCMC_MAX_SAMPLES = 200000"
    ```
- **実行が止まった**：`_tmp/mcmc_prod_run/logs/<ID>_try<N>.txt` と、`_tmp/mcmc_prod_run/nb/<ID>_try<N>.ipynb` のエラーのセルを見る。
  - 同じ材料で 2 回続けて失敗すると、その材料の残りは実行しない（台本の決まり）。
  - 直してから `--only` でやり直す。結果が半端に残ったモデルのフォルダは、先に `_to_delete/` へ移す。
- **フォルダの名前のエラー**（「MCMC 版の結果は、名前に『MCMC』を含む…」）：結果のフォルダの名前を確かめる。勾配法版のフォルダには書かない。
- **データ確認/ の表**：同じ学習結果フォルダの `データ確認/`（外れ値・データの概要など）は、実行のたびに同じ中身で書き直される。ノートの仕様で、勾配法版でも同じ（全厚みで確かめるため）。
